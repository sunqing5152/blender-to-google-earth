# 坐标轴与合并 OBJ：故障复盘

## 为什么酒店和 D8 会飞到空中？

太阳谷 V1 合并 OBJ 用过：

    x = old_x + dx
    y = old_y + dy
    z = old_z + dz

但源 OBJ 是 Y-up，因此 y 是高度，不是南北方向。真实偏移 dy 被错误用作建筑抬升：

- 酒店 +56.479m；
- D8 +22.716m；
- D2～D7 +0.692～5.377m。

随后在 V2 修复为：

    new_x = old_x + dx
    new_y = old_y + dz
    new_z = old_z - dy

其中 dx 东向、dy 北向、dz 垂直。这一映射仅适用于已确认使用该轴约定的 OBJ。不得对任意 OBJ 不经检查套用。

## 自动保护

- 在打包前计算每栋源模型的垂直最小值、最大值和尺寸。
- 合体后逐栋重新计算，确保水平位移不改变垂直最小值或高度。
- OBJ 合并时必须分别处理 v、vt、vn 索引，检查材质引用；不能简单拼接文本。
- 合体的每栋地理偏移从 KML 模型锚点动态计算，不写死 D1～D8。
- 当 KML 有不支持的非零旋转、缩放或不同高程模式，立即拒绝处理而不是生成看起来“成功”的错误模型。
